# Paradigm Ra — Production Site

Deployment-first Next.js site for Paradigm Ra.

## Before launch

1. Open `src/content/site.ts` and confirm the contact email.
2. Run:
   - `npm install`
   - `npm run dev`
3. Review mobile + desktop.
4. Run `npm run build`.
5. Push to GitHub and connect the repository to Netlify.

Netlify supports Next.js App Router with its Next.js integration, so no custom publish directory is required for this project.
